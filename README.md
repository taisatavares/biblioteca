# biblioteca
Este projeto foi desenvolvido utilizando **consultas em SQL** para coleta e tratamento dos dados, e posteriormente integrado ao **Power BI** para criação de um dashboard interativo. O objetivo é fornecer uma visão geral do acervo de uma biblioteca, auxiliando na gestão e tomada de decisões estratégicas.

## 🛠️ Tecnologias utilizadas

- SQL (para extração e tratamento dos dados)
- Power BI (para visualização e análise interativa)

## 🎯 Objetivos do projeto

- Visualizar a quantidade total de livros cadastrados
- Entender a distribuição por gênero, autor e preço
- Verificar a disponibilidade dos livros (emprestados ou não)


## 📊 Métricas e informações apresentadas

- Total de livros no acervo
- Gêneros mais presentes
- Autores mais populares
- Quantida de livros por editora
- Médias de páginas por assunto
